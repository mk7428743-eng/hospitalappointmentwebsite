# 🏥 Hospital Appointment Website

This is a full-stack Hospital Appointment Booking System built using Node.js, Express, MySQL, and a frontend (HTML/CSS/JS or React).

---

## 🚀 Features
- Doctor listing
- Book appointments
- View appointments


## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript 
- Backend: Node.js, Express.js
- Database: MySQL
- Other: dotenv, cors
